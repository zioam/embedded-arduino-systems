# Embedded Arduino Systems

## Overview

This repository is a personal collection of embedded systems developed over more than five years of hands-on experience in electronics and microcontroller programming. It contains independent Arduino-based projects that solve real-world control,
monitoring, and automation tasks using clean, reliable, and practical embedded design.

Each folder represents a complete, self-contained system with its own firmware, documentation, and hardware description.

---

## Contents

The projects in this repository include, but are not limited to:

- DC motor control and PWM systems  
- Sensor acquisition and signal processing  
- Display interfaces (7-segment, LCD, OLED)  
- Automation logic  
- Timing and control applications  
- Caudalimeter
- Mechanical arcade game
- Encoders
- Etc.

Every project is designed to be simple to understand, modify, and used for learning.

---

## Technical Focus

The main focus of this repository is:

- Raw C++ Arduino programming  
- Efficient I/O handling  
- Real-time control logic  
- Hardware-software integration  
- Practical embedded design patterns  

The code avoids unnecessary complexity and prioritizes clarity, stability, and educational value.

---

## Hardware Platforms

Most projects target:

- Arduino Uno / Nano  
- ATmega328P based boards  
- Common electronic components (motors, sensors, displays, drivers)

However, many examples are portable to other microcontrollers that support C++.
